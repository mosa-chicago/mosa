## Midwest Open Source Alliance — Website

The MOSA website is built with [Astro](https://astro.build/) and [Starlight](https://starlight.astro.build/).

### Development

```bash
npm install
npm run dev
```

### Build

```bash
npm run build
```

### Deployment

- **Production**: Deployed to [GitHub Pages](https://midwestopensourcealliance.org/) on push to `master` via GitHub Actions.
- **Preview**: Netlify automatically generates deploy previews for all pull requests.

### Contributing

Content lives in `src/content/docs/` as Markdown (`.md`) or MDX (`.mdx`) files. See the [Starlight docs](https://starlight.astro.build/getting-started/) for more information.

Midwest Open Source Alliance promotes the education, support and development of Drupal and related open source software within the Midwest Drupal community. We are a federal 501(c)(3) tax exempt organization (EIN 83-1560285).
